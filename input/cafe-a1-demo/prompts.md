# Café scene

The supplied cafe_two_people.png is used for this short reference episode.
For another scene, create an original 16:9 illustration with exactly two people:
Ben on the LEFT, Anna on the RIGHT, talking at an outdoor Berlin café. Both faces
must be clear, facing one another. Two cups on the table, a relaxed warm mood,
cohesive illustrated style. No baked-in text, captions, speech bubbles or watermark.
Save a new image as background.png and update assets.background in episode.json.

# Thumbnail concept

Use the same two characters, café and clothing. Focus on their expressions and
the coffee and tea. Leave clear space for “Im Café · Deutsch A1”. Generate a
separate 16:9 image if desired, add the final title manually, and configure it as
assets.thumbnail. Without a custom thumbnail, the pipeline makes a cover from
the scene and thumbnail_title.

# Editorial note

This is a roughly half-minute system test, not an 8–10 minute lesson. Its target
range is deliberately 25–60 seconds. New full lessons should set the target to
[480, 600] and contain enough varied dialogue to match that measured duration.
